Architecture

The VisionClient

Single entry point for everything. Flipping one boolean toggles between fixture-backed demo and live OCI calls.

from oci_vision import VisionClient

# Demo mode (zero credentials)
client = VisionClient(demo=True)
report = client.analyze("dog_closeup.jpg")

# Live mode (uses ~/.oci/config)
client = VisionClient()
report = client.analyze("oci://my-bucket/photo.jpg")

Quick start

Get started

Zero credentials required. Every surface works out of the box with --demo.

# Clone and install
git clone https://github.com/jasperan/oci-vision-ai.git
cd oci-vision-ai
pip install -e "."

# Try the CLI
oci-vision analyze dog_closeup.jpg --demo

# Launch the web dashboard
oci-vision web --demo

# Open the cockpit
oci-vision cockpit --demo
